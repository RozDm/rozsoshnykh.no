# Incident history — the "why" behind the hard rules

One line per incident, newest first: date · incident · the rule it produced.
Background for the rules in the `CLAUDE.md` files and `docs/gotchas.md`;
nothing here is needed for day-to-day changes. Read it when a rule looks wrong
or you are tempted to undo one. The full write-ups (numbers, run ids, dead
ends) are in git history: `git log -p -- docs/history.md` (the versions before this
table).

| Date | Incident | Rule it produced |
|---|---|---|
| 2026-11-16 | dependabot[bot] showed up in the repository's Contributors: #39 built on Dependabot's commit, so the squash added `Co-authored-by: dependabot[bot]` (the contributors API lists authors only, the box counts co-authors); the commit was corrected once, without it | `ci.yml` `authors`: every PR commit is the owner's, no `Co-authored-by`; Dependabot PRs are redone, never merged |
| 2026-11-16 | Worker CPU p99.9 was 9.7 ms against Free's 10 ms; each D1 call costs ~2 ms, and the contact route made four | Count binding calls per route (the contact route is one conditional `INSERT … SELECT … RETURNING`); `status-watchdog.yml`'s `cpu` job fails on p99.9 > 8 ms over 24 h. Longer edge-cache TTLs and cron precompute were measured and dropped |
| 2026-11-11 | Prefetch cost measured on a first view of `/`: 7 requests, 15.2 KB brotli | Nav, post cards and prev/next keep the default prefetch (hover-prefetch would save under 10 KB) |
| 2026-10-29 | `next/font/google` downloaded Intel One Mono on every build: Google down meant no deploy | The body font is self-hosted (`lib/server/fonts.ts`, `next/font/local`), one family per unicode-range subset, `display: 'optional'`, `adjustFontFallback: false`. Never `swap` without a hand-built metric-matched fallback `@font-face` (it reflowed every cold first paint) |
| 2026-10-26 | The stale banner greyed out while the cron was alive: late cron ticks plus the 60 s edge cache crossed 15 min | `STALE_AFTER_MS` is 20 min (`lib/shared/status.ts`); the watchdog's limit is 25 |
| 2026-10-23 | The Trends SVG's fixed 800-unit `viewBox` shrank 11 px labels to ~4 px at 390 px | The `viewBox` is the rendered width |
| 2026-10-22 | `workers.dev` served a second copy of the site whose `/api/*` 301'd cross-origin; a preview URL runs an old version against production D1, KV and mail | `workers_dev: false` and `preview_urls: false`, for good (owner's call) |
| 2026-10-22 | The deploy token was saved as `CW_API_TOKEN`; workflows read `CLOUDFLARE_API_TOKEN`, which still existed at repo level, so everything ran green on the old token | No repository-level secrets (`.github/CLAUDE.md`). Smoke never proves `AE_API_TOKEN` or `TURNSTILE_SECRET`: verify a new value with `analytics-report` and one real form message |
| 2026-10-22 | Pages came from the Worker, spending its free quota | `run_worker_first: ["/api/*", …]`; each page's hash CSP is a `<meta>` baked in at build, placed after the charset (a ~1 KB policy ahead of it pushed `<meta charset>` past 1,024 bytes). A miss never reaches the Worker |
| 2026-10-22 | Asset-served pages lost their ETag (every view re-downloaded) because Cloudflare strips it when Automatic HTTPS Rewrites, Email Obfuscation or insecure-JS replacement may rewrite HTML | `zone-rules.yml` turns all three off and its prod check wants a 304 on `If-None-Match` for `/` |
| 2026-10-22 | An opacity-0 start on the hero made its `<p>` the LCP at 3.7 s instead of ~1.1 s (throttled mobile) | No opacity-0 start on the first screen (hero, `app/template.tsx` on a document's first page) |
| 2026-10-22 | Turbopack's default 50 kB chunking copied shared client modules into several page chunks, fetched 3–5 times on a first view | `turbopackChunking: { minChunkSize: 15000 }` (cut 12–32 KB gzip; 20 kB cost ~2 KB, 10 kB added 8 scripts); `check:dict` guards it |
| 2026-10-22 | Next's `<Link href="/#x">` produced `/#main#about`, and setting `location.hash` jumped past the smooth scroll | In-page links are `HashLink`; `<html data-scroll-behavior="smooth">` stays |
| 2026-10-17 | The hard-coded Web Analytics token was dead (collector 404), and the zone's automatic mode injected a second beacon after the Worker, dropping the HTML ETag | Web Analytics removed (snippet, CSP hosts, privacy paragraph); `/api/visit` counts. Bringing RUM back means a CSP host, a privacy paragraph and a manual snippet with a live-checked token, never the automatic setup; `smoke.sh` "no edge script" guards it |
| 2026-10-17 | Writing `ai_bots_protection` through the API also reset `ai_training` to `disabled`, letting training crawlers in for about a minute | `zone-rules.yml` writes only `ai_training` (`disallow`), never `ai_bots_protection` (the coupling is one way) |
| 2026-10-15 | `public/_headers` gave a missing chunk's 404 `max-age=31536000, immutable`, and browsers keep it; a deploy propagates edge by edge, so new HTML can meet a chunk an edge lacks | A zone Response Header Transform Rule sets `no-store` on every 4xx/5xx (`zone-rules.yml`). Write it `ge 400`, never `ne 200`: a 304's headers would strip `immutable` from cached chunks |
| 2026-10-04 | `contact.at` is ISO (`…T…Z`) but windows compared it with SQLite `datetime('now', …)` (space-separated), so every same-day row counted as recent: duplicate and rate-limit checks were per-day | Windows are ISO cutoffs computed in JS (`CONTACT_WINDOWS_MS`, `isoCutoff`) and bound as parameters; route tests run against real SQLite with the production schema |
| 2026-10-04 | The newsletter sign-up was removed; its empty `subscribers` table was dropped from prod | A newsletter that returns needs its own schema, consent flow and a line in `/personvern` |
| 2026-07-03 | The D1 database died on Cloudflare's side (error 7500 on everything, Time Travel included); the deleted entry ghost-locks the old name `rozsoshnykh-metrics`, replacement is `rozsoshnykh-metrics-v2` | Don't try to reclaim the old name; `d1-repair.yml` is the kit (its `create` mode exists because the ghost defeats "already exists" checks) |
| 2026-07-03 | During that outage `geo`/`views` writes failed silently while Analytics Engine kept counting, and `/api/geo` answered an empty map with a 200 that smoke and the watchdog took for health | `METRICS_EPOCH` (AE can't be wiped, so a UTC epoch filters older points client-side); a failed read is a 503 and `status-watchdog.yml` probes `/api/geo` every run |
| 2026-07-03 | An epoch mid-bucket (17:00) dropped the whole straddling 6 h bucket on the 30d view | `METRICS_EPOCH` sits on a 6-hour UTC boundary (00/06/12/18), unit-tested in `tests/worker/domain/timeseries.test.ts`; after a `reset-metrics` run round UP |
| undated | Injecting the world-map SVG through a ref's `innerHTML` crashed prod; paths with an unresolved `var(--map-empty)` fill default to black and flashed or stuck black | SVG goes in via `dangerouslySetInnerHTML`; `build-world-svg.mjs` bakes a grey `fill`/`stroke` attribute on every path AND the CSS keeps `var()` fallbacks.
